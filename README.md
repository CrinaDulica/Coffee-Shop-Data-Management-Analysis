# Coffee-Shop-Data-Management-Analysis
This project focuses on managing and exploring Starbucks business data across Europe using Python, Streamlit, and SAS. It includes an interactive Streamlit application for visualizing store locations, analyzing sales, costs, profitability, and customer satisfaction through interactive charts and maps.

The project combines data preprocessing, statistical analysis, and machine learning techniques, including logistic regression and multiple linear regression (OLS). The SAS component focuses on data manipulation, filtering, aggregation, and statistical reporting to compare business performance across European countries.

Technologies: Python, Streamlit, Pandas, Plotly, Scikit-learn, Statsmodels, SAS.
